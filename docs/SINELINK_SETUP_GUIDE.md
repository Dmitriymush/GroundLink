# Sine.link + Антена — Інструкція з підключення

## Що потрібно мати

- ПК з GroundLink (macOS / Windows / Linux)
- Sine.link Master модем (USB) — спарений зі Slave на дроні
- Антенний пристрій з MAVLink (USB serial)
- 2 вільних USB порти

## Крок 1: Підключення обладнання

1. Підключити **Sine.link Master модем** до USB порту ПК
   - На macOS з'являться порти типу `/dev/tty.usbmodem*` або `/dev/tty.usbserial*`
   - На Windows — `COM3`, `COM4` і т.д.
   - На Linux — `/dev/ttyUSB0`, `/dev/ttyACM0` і т.д.
   - Модем має 2 UART через USB — один для контролю, другий для даних

2. Підключити **антенний пристрій** до іншого USB порту
   - З'явиться ще один serial порт

3. Переконатись що Sine.link Master спарений зі Slave на дроні і є радіозв'язок

## Крок 2: Запуск GroundLink

```bash
cd megapolis-ground
npm run dev
```

Або запустити зібраний додаток з `release/` папки.

## Крок 3: Налаштування в UI

1. Перейти на сторінку **Antenna Control** (меню зліва)

2. Увімкнути **Rotator** (перемикач зліва вгорі)

3. Вибрати режим **SineLink** (третя кнопка: `UDP | MAVLink | SineLink`)

4. Розгорнути панель (натиснути на стрілку вниз)

## Крок 4: Підключення Sine.link (вхід — координати дрона)

1. Натиснути **Scan ports** — з'явиться список доступних COM портів

2. В секції **"Sine.link (drone GPS)"**:
   - Вибрати COM порт модему зі списку
   - Якщо не знаєте який саме — спробуйте по черзі
   - Натиснути **Connect**

3. Статуси:
   - `Waiting...` (жовтий) — з'єднано, чекає GPS дані від дрона
   - `Receiving` (зелений) — координати дрона отримуються
   - Якщо помилка — перевірити порт, спробувати інший

## Крок 5: Підключення антени (вихід — servo команди)

1. В секції **"Antenna (servo output)"**:
   - Вибрати COM порт антенного пристрою
   - Натиснути **Connect**

2. Статуси:
   - `Waiting...` (жовтий) — з'єднано, чекає heartbeat від пристрою
   - `Connected` (зелений) — пристрій відповідає

## Крок 6: Налаштування GCS позиції

1. В секції **"GCS Position"**:
   - Натиснути **Auto** — спробує визначити координати автоматично
   - Або ввести вручну: Lat, Lon, Alt (метри)
   - Це позиція де стоїть антена (наземна станція)

## Крок 7: Увімкнення автонаведення

1. Увімкнути **Auto-track** (перемикач справа вгорі панелі)
   - Стане активним коли є: GCS позиція + координати дрона + обидва підключення

2. Коли Auto-track активний:
   - Компас автоматично повертається до напрямку на дрон
   - Показує: Bearing (азимут), Elevation (кут), Distance (дистанція)
   - Servo команди автоматично відправляються на антенний пристрій

3. Іконка цілі (зелена) пульсує коли автонаведення працює

## Крок 8: Перевірка роботи

В панелі повинно показувати:
```
SNS position (conf: 12)        ← якість позиції 0-15

Drone: 49.8397°, 24.0297°      ← координати дрона
Alt: 150m                       ← висота

Bearing: 45.3°                  ← напрямок на дрон
Elev: 12.1°                     ← кут піднесення
Dist: 1.2km                     ← дистанція
```

Антена повинна повертатись відповідно до Bearing/Elevation.

## Діагностика проблем

### Порти не з'являються після Scan
- Перевірити USB кабелі
- macOS: може потребувати дозвіл в System Preferences → Security
- Linux: `sudo usermod -aG dialout $USER` і перелогінитись
- Windows: встановити драйвер (CP210x або FTDI)

### Sine.link підключається але "Waiting..." надовго
- Перевірити що Master спарений зі Slave
- Перевірити що Slave на дроні увімкнений і є радіозв'язок
- Перевірити що на Slave налаштований SNS (GPS або Beacons)
- Спробувати інший COM порт (модем має 2 порти)

### Координати приходять але confidence = 0
- SNS ще не визначив позицію
- Перевірити що біконі/GPS налаштовані на Slave модемі
- Почекати — може потребувати час на ініціалізацію

### Антена не реагує
- Перевірити що антенний пристрій підключений і порт правильний
- Перевірити що Auto-track увімкнений
- Перевірити що bearing не в dead zone (164°-196°)
- Подивитись в DevTools Console (F12) на помилки

### Помилка "Wire SDK init failed"
- Перевірити що файл `wire/build/sine.wire/lib/sine_wire.wasm` існує
- Якщо запускаєте з build — переконатись що wire папка скопійована

## Baud Rate

За замовчуванням `115200`. Якщо потрібно змінити — в localStorage:
```
sinelink-baud = 115200
antenna-mavlink-baud = 115200
```

## Режими роботи (переключення)

| Режим | Вхід координат | Вихід на антену |
|-------|---------------|----------------|
| **UDP** | Ручне керування | UDP → WIFI232-B2 |
| **MAVLink** | MAVLink UDP (порт 14550) | UDP → WIFI232-B2 |
| **SineLink** | Sine.link serial (MAV FTP) | MAVLink serial (DO_SET_SERVO) |

Можна вільно перемикатись між режимами. Налаштування кожного режиму зберігаються.
