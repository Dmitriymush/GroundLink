# Antenna Control — User Manual

## Обладнання

Для повноцінної роботи потрібно:

1. **Sine.link Master модем** — підключений до ПК по USB. Дає 2 віртуальні COM порти. Через один з них GroundLink отримує координати дрона (SNS позиція).
2. **Антенний пристрій** — підключений до ПК по USB (другий serial порт). Приймає MAVLink команди для повороту (servo).
3. **Sine.link Slave модем** — встановлений на дроні, спарений з Master.
4. **Антена** — фізично підключена до антенного пристрою.

```
[Drone + Slave модем]  ~~~radio~~~  [Master модем] --USB--> [ПК з GroundLink]
                                                                    |
                                                          [Антенний пристрій] --USB--> [ПК]
                                                                    |
                                                              [Антена]
```

## Три режими роботи

Перемикач режимів знаходиться в панелі **Rotator** (потрібно увімкнути перемикач "Rotator"):

| Режим | Джерело координат | Керування антеною | Коли використовувати |
|---|---|---|---|
| **UDP** | Ручне (компас) | UDP → WIFI232-B2 | Ручне керування, тестування |
| **MAVLink** | MAVLink UDP (автопілот) | UDP → WIFI232-B2 | Автонаведення без Sine.link |
| **SineLink** | Sine.link SNS (модем) | MAVLink serial (servo) | Автонаведення з Sine.link |

## Режим SineLink — повна інструкція

### Крок 1: Підключити обладнання

1. Підключити **Sine.link Master модем** до USB порту ПК
2. Підключити **антенний пристрій** до іншого USB порту ПК
3. Переконатись що Master спарений зі Slave на дроні
4. Дочекатись поки ОС розпізнає пристрої (з'являться COM порти)

### Крок 2: Запустити GroundLink

```bash
npm run dev
```
або запустити зібраний додаток.

### Крок 3: Налаштувати Antenna Control

1. Відкрити сторінку **Antenna Control** (меню зліва)
2. Увімкнути перемикач **Rotator**
3. Вибрати режим **SineLink**
4. Розгорнути панель (натиснути на стрілку)

### Крок 4: Сканувати порти

1. Натиснути кнопку **Scan ports**
2. В списках з'являться доступні COM порти
   - Linux: `/dev/ttyUSB0`, `/dev/ttyUSB1`, `/dev/ttyACM0`, ...
   - macOS: `/dev/tty.usbserial-XXXX`, `/dev/tty.usbmodem-XXXX`, ...
   - Windows: `COM3`, `COM4`, ...

### Крок 5: Підключити Sine.link (вхід координат)

1. В секції **Sine.link (drone GPS)** вибрати COM порт модему
   - Зазвичай це порт з vendor `1939` або з назвою що містить "Sine"
   - Якщо не впевнені — спробувати один, якщо не працює — інший
2. Натиснути **Connect**
3. Статуси:
   - **Waiting...** (жовтий) — порт відкрито, чекаємо SNS дані
   - **Receiving** (зелений) — координати дрона отримуються
   - Помилка — неправильний порт або модем не відповідає

### Крок 6: Підключити антену (вихід servo)

1. В секції **Antenna (servo output)** вибрати COM порт антенного пристрою
   - Це інший порт, не той що Sine.link
2. Натиснути **Connect**
3. Статуси:
   - **Waiting...** (жовтий) — порт відкрито, чекаємо heartbeat від пристрою
   - **Connected** (зелений) — пристрій відповідає

### Крок 7: Ввести позицію GCS (наземна станція)

1. В секції **GCS Position** натиснути **Auto** для автовизначення
   - Або ввести координати вручну: Lat, Lon, Alt(m)
2. Позиція GCS — це місце де стоїть антена
3. Зберігається між сесіями

### Крок 8: Увімкнути Auto-track

1. Увімкнути перемикач **Auto-track**
   - Доступний тільки коли GCS позиція введена І координати дрона отримуються
2. Коли увімкнено:
   - Компас автоматично повертається до дрона
   - Servo команди відправляються на антенний пристрій
   - Іконка прицілу пульсує зеленим

### Крок 9: Перевірити телеметрію

В нижній частині панелі відображається:
- **Drone**: координати дрона (lat, lon)
- **Alt**: висота дрона (м)
- **Bearing**: азимут від GCS до дрона (°)
- **Elev**: кут підйому до дрона (°)
- **Dist**: дистанція до дрона (м/км)
- **SNS position (conf: X)**: впевненість позиції (0-15, чим більше тим краще)

## Режим UDP — ручне керування

### Підключення

1. Увімкнути **Rotator**, вибрати режим **UDP**
2. Ввести IP адресу WIFI232-B2 модуля (за замовчуванням `192.168.1.200`)
3. Натиснути **Connect**
4. Статуси:
   - **Waiting...** — UDP з'єднання створено, чекаємо телеметрію від ротатора
   - **Connected** — ротатор відповідає
   - **No response** — ротатор не відповідає (перевірити IP/мережу)

### Керування

- **Компас** — натиснути і тягнути стрілку
- **Стрілки клавіатури** — ←→ азимут, ↑↓ елевація (Shift для швидкого кроку)
- **Кнопки ±** — покроковий рух
- **Power On/Off** — увімкнути/вимкнути відправку команд
- **Мертва зона**: 164°-196° — антена не може повернутись назад, з'являється попередження

### Телеметрія

- **Azimuth**: поточна позиція компасу ротатора (°)
- **Battery**: напруга батареї ротатора (V)
- **Sent**: кількість відправлених команд

## Режим MAVLink — автонаведення через автопілот

### Підключення

1. Увімкнути **Rotator**, вибрати режим **MAVLink**
2. Ввести UDP порт для прийому MAVLink телеметрії (за замовчуванням `14550`)
3. Натиснути **Listen**
4. Ввести GCS позицію (Auto або вручну)
5. Увімкнути **Auto-track**

### Джерело координат

Координати дрона приходять по MAVLink UDP (GLOBAL_POSITION_INT) від:
- ArduPilot/PX4 через MAVLink proxy (mavlink-router, mavp2p)
- RPanion-server
- Будь-яке ПЗ що транслює MAVLink телеметрію на UDP порт

### Керування антеною

В цьому режимі антена керується через **UDP** (WIFI232-B2), як в ручному режимі. Різниця тільки в тому що азимут/елевація обчислюються автоматично з координат дрона.

## Плаваюче вікно

Натиснути іконку **↗** в правому верхньому куті сторінки Antenna Control. Відкриється окреме вікно яке:
- Завжди поверх інших вікон
- Має всі ті самі елементи керування
- Має пріоритет над головним вікном для відправки команд

## Troubleshooting

### Sine.link не підключається
- Перевірити що модем підключений по USB
- Перевірити що драйвери встановлені (Linux: `sudo usermod -aG dialout $USER`, перелогінитись)
- Спробувати інший COM порт
- Перевірити baud rate (за замовчуванням 115200)

### Координати не приходять (Waiting...)
- Перевірити що Master і Slave спаровані
- Перевірити що Slave увімкнений і в зоні радіо
- Перевірити SNS profile на модемі (pstBeacons, pstGps, pstExternal)
- confidence = 0 означає що SNS не може визначити позицію

### Антена не рухається
- Перевірити що антенний пристрій підключений
- Перевірити що обраний правильний COM порт (не той що Sine.link)
- Перевірити Power On
- Перевірити що немає мертвої зони (164°-196°)
- Перевірити що Auto-track увімкнений

### Білий екран при запуску (Linux)
- Проблема з node-hid. Переконатись що є `libusb-1.0`:
  ```bash
  sudo apt install libusb-1.0-0-dev libudev-dev
  npm rebuild
  ```

### COM порти не з'являються після Scan
- Перевірити USB підключення
- Linux: перевірити права: `ls -la /dev/ttyUSB*`
- macOS: перевірити в System Preferences → Security
- Натиснути Scan ports повторно

## Налаштування (для досвідчених)

Параметри зберігаються в localStorage браузера і доступні в DevTools:

| Ключ | Опис | За замовчуванням |
|---|---|---|
| `sinelink-port` | COM порт Sine.link | (пустий) |
| `sinelink-baud` | Baud rate Sine.link | 115200 |
| `sinelink-poll-interval` | Інтервал polling (мс) | 500 |
| `antenna-mavlink-port` | COM порт антени | (пустий) |
| `antenna-mavlink-baud` | Baud rate антени | 115200 |
| `antenna-mavlink-target-sys` | MAVLink target system ID | 1 |
| `antenna-mavlink-target-comp` | MAVLink target component ID | 1 |
| `antenna-mavlink-az-servo` | Канал servo для азимута | 1 |
| `antenna-mavlink-el-servo` | Канал servo для елевації | 2 |
| `sinelink-gcs-lat` | GCS широта | 0 |
| `sinelink-gcs-lon` | GCS довгота | 0 |
| `sinelink-gcs-alt` | GCS висота (м) | 0 |
| `sinelink-tracking-enabled` | Auto-track увімкнений | true |
