## 1. Загальний огляд

Цей документ описує повний план інтеграції системи дистанційного керування ротатором антени в додаток наземної станції GroundLink. Система дозволяє операторам віддалено керувати азимутом та кутом підйому антени через WiFi з'єднання Starlink.

### Компоненти системи

| Компонент | Призначення | Статус |
|-----------|-------------|--------|
| Фізичний ротатор | Механізм обертання | Потрібен |
| Мікроконтролер | Керування моторами та протокол | Потрібен |
| WIFI232-B2 | UART-WiFi міст | Потрібен |
| Starlink | Мережеве з'єднання | Потрібен |
| Додаток GroundLink | Інтерфейс користувача | Буде реалізовано |

### Потік даних високого рівня

```
[GroundLink ПК] ──UDP──> [Starlink] ──WiFi──> [WIFI232-B2] ──UART──> [МК] ──PWM──> [Мотори]
                                                                        │
[GroundLink ПК] <──UDP── [Starlink] <──WiFi── [WIFI232-B2] <──UART── [МК] <──ADC── [Датчики]
```

## 4. Рівень 1: Фізичне обладнання

### 4.1 Механічний вузол ротатора

Ротатор повинен забезпечувати:
- **Обертання азимуту**: 360° (або обмежений діапазон з мертвою зоною)
- **Обертання підйому**: 0° до 90° (від горизонту до зеніту)
- **Кріплення**: Надійне кріплення антени
- **Захист від погоди**: Можливість роботи на вулиці

### 4.2 Вибір моторів

| Параметр | Мотор азимуту | Мотор підйому |
|----------|---------------|---------------|
| Тип | DC з редуктором / Кроковий | DC з редуктором / Кроковий |
| Момент | На основі ваги антени | На основі ваги антени |
| Швидкість | 5-10 об/хв рекомендовано | 5-10 об/хв рекомендовано |
| Напруга | 12В або 24В | 12В або 24В |

### 4.3 Зворотній зв'язок положення

**Варіант А: Потенціометри**
- Простий, аналоговий вихід
- Обмежене обертання (типово 270°)
- Низька вартість

**Варіант Б: Енкодери**
- Цифровий, вища точність
- Необмежене обертання (інкрементальний) або абсолютний
- Вища вартість

### 4.4 Обробка мертвої зони

Згідно з протоколом, існує **мертва зона**, куди ротатор не може вказувати:
- **Мертва зона**: 164° до 196° (азимут)
- Програмне забезпечення повинно запобігати командам у цьому діапазоні
- Апаратура може мати фізичні обмежувачі

## 5. Рівень 2: Мікроконтролер

### 5.1 Вимоги до прошивки

Прошивка мікроконтролера повинна:

1. **Парсити вхідні команди** через UART
2. **Керувати моторами** за допомогою PID або простого пропорційного керування
3. **Читати датчики положення** (енкодери/потенціометри)
4. **Відправляти телеметрію** назад через UART
5. **Обробляти обмеження безпеки** (кінцеві точки, мертві зони)

### 5.2 Протокол зв'язку

#### Командний кадр (отриманий від ПК)

```
T:<transmitter_id>;R:<receiver_id>;X:<pwm_value>;Y:<elevation_cmd>;CH:<checksum>;
```

| Поле | Опис | Діапазон | Приклад |
|------|------|----------|---------|
| T | ID передавача | Ціле число | 101 |
| R | ID приймача | Ціле число | 102 |
| X | PWM азимуту | 540-2400 | 1470 |
| Y | Команда підйому | 0-95 | 45 |
| CH | Контрольна сума | Рядок | "10110214745" |

**Розрахунок контрольної суми**: Конкатенація T + R + X + Y як рядки

**Приклад команди**: `T:101;R:102;X:1470;Y:45;CH:101102147045;`

#### Кадр телеметрії (відправлений до ПК)

```
T:<transmitter_id>
R:<receiver_id>
COM:<compass_degrees>
V:<voltage>
CH:<checksum>
```

| Поле | Опис | Діапазон | Приклад |
|------|------|----------|---------|
| T | ID передавача | Ціле число | 101 |
| R | ID приймача | Ціле число | 102 |
| COM | Поточний азимут | Градуси | 45 |
| V | Напруга батареї | Вольти | 12.3 |
| CH | Контрольна сума | Рядок | "10110245123" |

**Приклад телеметрії**:
```
T:101
R:102
COM:45
V:12.3
CH:10110245123
```

### 5.3 Приклад прошивки Arduino

```cpp
// ============================================================
// ПРОШИВКА КОНТРОЛЕРА РОТАТОРА
// Для Arduino Mega / STM32 / ESP32
// ============================================================

#include <Arduino.h>

// Визначення пінів
#define AZ_MOTOR_PWM    9
#define AZ_MOTOR_DIR    8
#define EL_MOTOR_PWM    10
#define EL_MOTOR_DIR    11
#define AZ_ENCODER_PIN  A0
#define EL_ENCODER_PIN  A1
#define VOLTAGE_PIN     A2

// Константи протоколу
#define TRANSMITTER_ID  101
#define RECEIVER_ID     102
#define PWM_MIN         540
#define PWM_MAX         2400
#define PWM_CENTER      1470

// Глобальні змінні
String inputBuffer = "";
int targetAzimuthPWM = PWM_CENTER;
int targetElevationCmd = 45;
unsigned long lastTelemetryTime = 0;
const unsigned long TELEMETRY_INTERVAL = 200; // мс

void setup() {
  // Ініціалізація Serial для зв'язку з WIFI232-B2
  Serial1.begin(115200);  // Апаратний UART до WIFI232
  Serial.begin(115200);   // Відладка USB

  // Ініціалізація пінів моторів
  pinMode(AZ_MOTOR_PWM, OUTPUT);
  pinMode(AZ_MOTOR_DIR, OUTPUT);
  pinMode(EL_MOTOR_PWM, OUTPUT);
  pinMode(EL_MOTOR_DIR, OUTPUT);

  Serial.println("Контролер ротатора запущено");
}

void loop() {
  // Читання вхідних команд
  while (Serial1.available()) {
    char c = Serial1.read();
    if (c == '\n' || c == ';') {
      if (inputBuffer.length() > 0) {
        parseCommand(inputBuffer);
        inputBuffer = "";
      }
    } else {
      inputBuffer += c;
    }
  }

  // Оновлення керування моторами
  updateMotors();

  // Періодична відправка телеметрії
  if (millis() - lastTelemetryTime >= TELEMETRY_INTERVAL) {
    sendTelemetry();
    lastTelemetryTime = millis();
  }
}

void parseCommand(String cmd) {
  // Парсинг: T:101;R:102;X:1470;Y:45;CH:xxx

  int xPos = cmd.indexOf("X:");
  int yPos = cmd.indexOf("Y:");

  if (xPos != -1) {
    int xEnd = cmd.indexOf(';', xPos);
    if (xEnd == -1) xEnd = cmd.length();
    targetAzimuthPWM = cmd.substring(xPos + 2, xEnd).toInt();
    targetAzimuthPWM = constrain(targetAzimuthPWM, PWM_MIN, PWM_MAX);
  }

  if (yPos != -1) {
    int yEnd = cmd.indexOf(';', yPos);
    if (yEnd == -1) yEnd = cmd.length();
    targetElevationCmd = cmd.substring(yPos + 2, yEnd).toInt();
    targetElevationCmd = constrain(targetElevationCmd, 0, 95);
  }
}

void updateMotors() {
  // Читання поточних положень
  int currentAzRaw = analogRead(AZ_ENCODER_PIN);
  int currentElRaw = analogRead(EL_ENCODER_PIN);

  // Маппінг показань енкодера до діапазону PWM
  int currentAzPWM = map(currentAzRaw, 0, 1023, PWM_MIN, PWM_MAX);
  int currentElCmd = map(currentElRaw, 0, 1023, 0, 95);

  // Просте пропорційне керування азимутом
  int azError = targetAzimuthPWM - currentAzPWM;
  int azSpeed = constrain(abs(azError) / 4, 0, 255);

  if (abs(azError) > 10) {
    digitalWrite(AZ_MOTOR_DIR, azError > 0 ? HIGH : LOW);
    analogWrite(AZ_MOTOR_PWM, azSpeed);
  } else {
    analogWrite(AZ_MOTOR_PWM, 0);
  }

  // Просте пропорційне керування підйомом
  int elError = targetElevationCmd - currentElCmd;
  int elSpeed = constrain(abs(elError) * 3, 0, 255);

  if (abs(elError) > 2) {
    digitalWrite(EL_MOTOR_DIR, elError > 0 ? HIGH : LOW);
    analogWrite(EL_MOTOR_PWM, elSpeed);
  } else {
    analogWrite(EL_MOTOR_PWM, 0);
  }
}

void sendTelemetry() {
  // Читання датчиків
  int azRaw = analogRead(AZ_ENCODER_PIN);
  int voltageRaw = analogRead(VOLTAGE_PIN);

  // Конвертація в градуси
  int compassDeg = map(azRaw, 0, 1023, 0, 359);
  float voltage = voltageRaw * (5.0 / 1023.0) * 4.0; // Дільник 4:1

  // Формування контрольної суми
  String checksum = String(TRANSMITTER_ID) + String(RECEIVER_ID) +
                    String(compassDeg) + String((int)(voltage * 10));

  // Відправка телеметрії
  Serial1.print("T:"); Serial1.println(TRANSMITTER_ID);
  Serial1.print("R:"); Serial1.println(RECEIVER_ID);
  Serial1.print("COM:"); Serial1.println(compassDeg);
  Serial1.print("V:"); Serial1.println(voltage, 1);
  Serial1.print("CH:"); Serial1.println(checksum);
}
```

## 6. Рівень 3: Налаштування WIFI232-B2

### 6.1 Початкове підключення

**Крок 1: Увімкніть модуль**
- Підключіть 3.3В (або 5В з вбудованим стабілізатором) та GND
- Зачекайте на завантаження (індикатори LED)

**Крок 2: Підключіться до точки доступу модуля**
- За замовчуванням WIFI232-B2 створює точку доступу
- SSID: Зазвичай `WIFI232_xxxx` або подібний
- Підключіть ваш ПК до цієї WiFi мережі

**Крок 3: Доступ до веб-інтерфейсу**
- Відкрийте браузер: `http://10.10.100.254`
- Або використовуйте інструмент конфігурації Waveshare

### 6.2 Конфігурація через AT команди

Підключіться до модуля через послідовний термінал (115200 бод, 8N1) або telnet і відправте наступні команди:

#### 6.2.1 Вхід в режим команд

Зачекайте 1 секунду, потім відправте:
```
AT
```
Очікувана відповідь: `+ok`

#### 6.2.2 Налаштування режиму WiFi станції

```
AT+WMODE=STA
```
Відповідь: `+ok`

#### 6.2.3 Встановлення цільової WiFi мережі (Starlink)

```
AT+WSSSID=НАЗВА_ВАШОЇ_МЕРЕЖІ_STARLINK
```
Відповідь: `+ok`

```
AT+WSKEY=WPA2PSK,AES,ВАШ_ПАРОЛЬ_STARLINK
```
Відповідь: `+ok`

#### 6.2.4 Налаштування мережевого протоколу (UDP сервер)

```
AT+NETP=UDP,SERVER,24448,0.0.0.0
```
Відповідь: `+ok`

Параметри:
- `UDP` - Тип протоколу
- `SERVER` - Режим роботи
- `24448` - Номер порту
- `0.0.0.0` - Приймати з будь-якої IP

#### 6.2.5 Налаштування параметрів UART

```
AT+UART=115200,8,1,NONE,NFC
```
Відповідь: `+ok`

Параметри:
- `115200` - Швидкість передачі
- `8` - Біти даних
- `1` - Стоп-біти
- `NONE` - Без парності
- `NFC` - Без контролю потоку

#### 6.2.6 Опціонально: Встановлення статичної IP (якщо потрібно)

```
AT+WANN=STATIC,192.168.1.100,255.255.255.0,192.168.1.1
```

Або використовуйте DHCP (за замовчуванням):
```
AT+WANN=DHCP
```

#### 6.2.7 Збереження та перезапуск

```
AT+Z
```

Модуль перезапуститься та підключиться до WiFi Starlink.

### 6.3 Повний скрипт конфігурації

Збережіть це як довідку:

```bash
# Скрипт конфігурації WIFI232-B2
# ================================
# Виконуйте ці команди через послідовний термінал на 115200 бод

+++                                          # Вхід в режим команд (зачекайте 1 сек)
AT                                           # Тест з'єднання
AT+WMODE=STA                                 # Режим станції (підключення до існуючої WiFi)
AT+WSSSID=Starlink_Network_Name              # SSID вашого Starlink
AT+WSKEY=WPA2PSK,AES,YourStarlinkPassword    # Налаштування безпеки WiFi
AT+NETP=UDP,SERVER,24448,0.0.0.0             # UDP сервер на порту 24448
AT+UART=115200,8,1,NONE,NFC                  # UART: 115200 бод, 8N1, без контролю потоку
AT+WANN=DHCP                                 # Використовувати DHCP для IP адреси
AT+Z                                         # Зберегти та перезапустити

# Після перезапуску знайдіть IP пристрою:
# - Перевірте список DHCP клієнтів вашого роутера Starlink
# - Або використовуйте мережевий сканер
# - Або налаштуйте статичну IP вище
```

### 6.4 Перевірка конфігурації

Після перезапуску:

1. **Перевірте WiFi з'єднання**: LED модуля повинен показувати стан підключення
2. **Знайдіть IP адресу**: Перевірте DHCP оренди роутера Starlink
3. **Тестуйте UDP з'єднання**: Використовуйте netcat або подібний інструмент:
   ```bash
   # Відправка тестової команди
   echo "T:101;R:102;X:1470;Y:45;CH:test;" | nc -u 192.168.1.100 24448
   ```

## 7. Рівень 4: Мережева конфігурація

### 7.1 Налаштування роутера Starlink

1. **Переконайтеся, що WIFI232-B2 підключений**: Перевірте підключені пристрої в додатку Starlink
2. **Запишіть IP адресу**: WIFI232-B2 отримає DHCP адресу (наприклад, 192.168.1.100)
3. **Опціонально - Зарезервуйте IP**: Встановіть резервацію DHCP для постійної адресації

### 7.2 Прокидання портів (якщо потрібно)

Якщо оператор в іншій мережі (не в тій самій Starlink):

1. **Роутер Starlink**: Прокиньте UDP порт 24448 на IP WIFI232-B2
2. **Примітка**: Starlink може мати обмеження CGNAT - розгляньте VPN замість цього

### 7.3 Налаштування VPN (Рекомендовано)

Для надійного віддаленого доступу:

1. **Встановіть VPN сервер** на пристрої на польовому майданчику
2. **Підключіть ПК оператора** до VPN
3. **Доступ до WIFI232-B2** через VPN тунель використовуючи локальну IP

## 11. Вирішення проблем

### Немає зв'язку

| Симптом | Перевірка | Рішення |
|---------|-----------|---------|
| ПК не може достукатися до WIFI232 | Ping тест | Перевірте мережу, firewall |
| WIFI232 не в мережі | Список DHCP Starlink | Переналаштуйте WiFi |
| Команди відправляються, але немає відповіді | Моніторинг на МК | Перевірте UART, швидкість |
| Телеметрія спотворена | Формат протоколу | Перевірте розділювачі, кодування |

### Проблеми з моторами

| Симптом | Перевірка | Рішення |
|---------|-----------|---------|
| Мотор не рухається | Блок живлення | Перевірте напругу, струм |
| Мотор рухається в неправильному напрямку | Підключення | Поміняйте дроти або логіку DIR |
| Мотор перестрибує | Налаштування PID | Відрегулюйте коефіцієнти |
| Позиція неточна | Енкодер | Відкалібруйте мапінг датчика |

## Додаток A: Коротка довідка

### Підсумок AT команд

```
+++                                    # Вхід в режим AT
AT+WMODE=STA                          # Режим станції
AT+WSSSID=<ssid>                      # Встановити WiFi SSID
AT+WSKEY=WPA2PSK,AES,<password>       # Встановити пароль WiFi
AT+NETP=UDP,SERVER,24448,0.0.0.0      # Режим UDP сервера
AT+UART=115200,8,1,NONE,NFC           # Налаштування UART
AT+Z                                  # Зберегти та перезапустити
```

### Підсумок протоколу

**TX (ПК → Ротатор):**
```
T:101;R:102;X:1470;Y:45;CH:101102147045;
```

**RX (Ротатор → ПК):**
```
T:101
R:102
COM:45
V:12.3
CH:10110245123
```

```
D8  - AZ Напрямок

A0  - AZ Енкодер

A2  - Датчик напруги
TX1 - WIFI232 RX
RX1 - WIFI232 TX
```
