## 2. ОДНОРАЗОВЕ налаштування

> **Ця конфігурація виконується ОДИН РАЗ. Налаштування зберігаються назавжди.**

### Крок 2.1: Зберіть дані WiFi Starlink

Перед початком вам потрібно:

```
┌─────────────────────────────────────────────────────────────────┐
│  ІНФОРМАЦІЯ ПРО WIFI STARLINK                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Назва мережі (SSID):  _________________________________        │
│                        Приклад: STARLINK-ABC123-5G              │
│                                                                 │
│  Пароль:               _________________________________        │
│                        Приклад: MySecurePassword123             │
│                                                                 │
│  IP роутера:           192.168.1.1 (зазвичай за замовчуванням) │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**Як знайти:**
- Відкрийте додаток Starlink на телефоні
- Перейдіть в Налаштування → WiFi
- Запишіть назву мережі та пароль

---

### Крок 2.2: Підключіть WIFI232-B2 до ПК

**Схема підключення:**

```
┌─────────────────┐                    ┌─────────────────┐
│   USB-UART      │                    │   WIFI232-B2    │
│    Адаптер      │                    │                 │
│                 │                    │                 │
│      TX  ───────┼────────────────────┼───► RX          │
│      RX  ◄──────┼────────────────────┼──── TX          │
│      GND ───────┼────────────────────┼──── GND         │
│      3.3V ──────┼────────────────────┼───► VCC         │
│                 │                    │                 │
│  [USB до ПК]    │                    │   [Антена]      │
└─────────────────┘                    └─────────────────┘

⚠️  ВАЖЛИВО:
    - TX підключається до RX (перехресно!)
    - RX підключається до TX (перехресно!)
    - Перевірте напругу: 3.3В або 5В (дивіться специфікацію модуля)
```

**Фізичне підключення:**

1. Підключіть з'єднувальні дроти як показано вище
2. Вставте USB адаптер у ваш ПК
3. Світлодіод WIFI232-B2 повинен засвітитися (живлення є)

---

### Крок 2.3: Знайдіть COM порт

#### Windows:

1. Натисніть `Win + X` → Диспетчер пристроїв
2. Розгорніть **Порти (COM і LPT)**
3. Знайдіть ваш адаптер: `USB-SERIAL CH340 (COM3)` або подібне
4. Запишіть номер COM порту (наприклад, `COM3`)

```
Диспетчер пристроїв
└── Порти (COM і LPT)
    └── USB-SERIAL CH340 (COM3)  ◄── Це ваш порт
```

#### macOS:

Відкрийте Термінал і виконайте:
```bash
ls /dev/tty.usb*
```

Приклад результату:
```
/dev/tty.usbserial-1420    ◄── Це ваш порт
```

#### Linux:

Відкрийте Термінал і виконайте:
```bash
ls /dev/ttyUSB*
```

Приклад результату:
```
/dev/ttyUSB0    ◄── Це ваш порт
```

---

### Крок 2.4: Відкрийте послідовний термінал

#### Windows (PuTTY):

1. Завантажте PuTTY: https://putty.org
2. Відкрийте PuTTY
3. Налаштуйте:
   - Тип з'єднання: **Serial**
   - Послідовна лінія: **COM3** (ваш порт)
   - Швидкість: **115200**
4. Натисніть **Open**

```
┌─────────────────────────────────────┐
│ Конфігурація PuTTY                  │
├─────────────────────────────────────┤
│                                     │
│ Тип з'єднання:                      │
│ ○ Raw  ○ Telnet  ○ Rlogin  ○ SSH   │
│ ● Serial                            │
│                                     │
│ Послідовна лінія: [ COM3      ]     │
│ Швидкість:        [ 115200    ]     │
│                                     │
│         [ Open ]  [ Cancel ]        │
└─────────────────────────────────────┘
```

#### macOS (CoolTerm):

1. Завантажте CoolTerm: https://freeware.the-meiers.org
2. Відкрийте CoolTerm
3. Options → Serial Port:
   - Port: `/dev/tty.usbserial-1420`
   - Baud-rate: `115200`
   - Data Bits: `8`
   - Parity: `None`
   - Stop Bits: `1`
4. Натисніть **Connect**

#### macOS/Linux (Термінал):

```bash
screen /dev/tty.usbserial-1420 115200
# або
screen /dev/ttyUSB0 115200
```

Щоб вийти з screen: Натисніть `Ctrl+A`, потім `K`, потім `Y`

---

### Крок 2.5: Увійдіть в режим AT команд

У вашому послідовному терміналі:

**Крок 1:** Введіть `+++` і **зачекайте 2 секунди** (не натискайте Enter)

```
+++
```

**Крок 2:** Через 2 секунди введіть `AT` і натисніть Enter:

```
AT
```

**Очікувана відповідь:**
```
+ok
```

Якщо ви бачите `+ok`, ви підключені! Якщо ні, дивіться [Вирішення проблем](#6-вирішення-проблем).

---

### Крок 2.6: Налаштуйте WIFI232-B2

Відправляйте ці команди **по одній**, натискаючи Enter після кожної, і чекайте `+ok`:

#### Команда 1: Встановіть режим WiFi станції

```
AT+WMODE=STA
```
Відповідь: `+ok`

#### Команда 2: Встановіть назву WiFi Starlink (SSID)

```
AT+WSSSID=НАЗВА_ВАШОГО_STARLINK_WIFI
```
Відповідь: `+ok`

**Приклад:**
```
AT+WSSSID=STARLINK-ABC123-5G
```

#### Команда 3: Встановіть пароль WiFi

```
AT+WSKEY=WPA2PSK,AES,ВАШ_ПАРОЛЬ_STARLINK
```
Відповідь: `+ok`

**Приклад:**
```
AT+WSKEY=WPA2PSK,AES,MySecurePassword123
```

#### Команда 4: Встановіть режим UDP сервера

```
AT+NETP=UDP,SERVER,24448,0.0.0.0
```
Відповідь: `+ok`

Це налаштовує:
- Протокол: UDP
- Режим: Сервер (слухає)
- Порт: 24448
- Приймати від: Будь-якої IP адреси

#### Команда 5: Встановіть параметри UART

```
AT+UART=115200,8,1,NONE,NFC
```
Відповідь: `+ok`

Це налаштовує:
- Швидкість: 115200 бод
- Біти даних: 8
- Стоп-біти: 1
- Парність: Немає
- Контроль потоку: Немає

#### Команда 6: Встановіть статичну IP (Рекомендовано)

```
AT+WANN=STATIC,192.168.1.200,255.255.255.0,192.168.1.1
```
Відповідь: `+ok`

Це встановлює:
- IP адреса: `192.168.1.200` (завжди однакова)
- Маска підмережі: `255.255.255.0`
- Шлюз: `192.168.1.1` (роутер Starlink)

**Альтернатива - Використовувати DHCP (IP може змінюватися):**
```
AT+WANN=DHCP
```

#### Команда 7: Зберегти і перезапустити

```
AT+Z
```

Модуль перезапуститься. З'єднання з послідовним терміналом буде втрачено - це нормально!

---

### Крок 2.7: Повний список команд

Довідка для копіювання (замініть на ваші значення):

```
+++
AT
AT+WMODE=STA
AT+WSSSID=STARLINK-ABC123-5G
AT+WSKEY=WPA2PSK,AES,MySecurePassword123
AT+NETP=UDP,SERVER,24448,0.0.0.0
AT+UART=115200,8,1,NONE,NFC
AT+WANN=STATIC,192.168.1.200,255.255.255.0,192.168.1.1
AT+Z
```

## 3. Перевірка конфігурації

### Крок 3.1: Перевірте статус світлодіода

Після перезапуску спостерігайте за світлодіодами WIFI232-B2:

| Стан світлодіода  | Значення            |
|-------------------|---------------------|
| Швидке блимання   | Пошук WiFi          |
| Повільне блимання | Підключення до WiFi |
| Постійно світить  | Підключено до WiFi  |

**Зачекайте 10-30 секунд** для встановлення з'єднання.

---

### Крок 3.2: Перевірте IP адресу

#### Метод А: Перевірте роутер Starlink

1. Відкрийте додаток Starlink на телефоні
2. Перейдіть в Мережа → Пристрої
3. Знайдіть пристрій з назвою "WIFI232" або подібне
4. Запишіть IP адресу (повинна бути `192.168.1.200` якщо встановили статичну)

#### Метод Б: Запитайте модуль (перепідключіть serial)

Якщо ви перепідключите USB-UART адаптер:

```
+++
AT+WANN
```

Відповідь:
```
+ok=STATIC,192.168.1.200,255.255.255.0,192.168.1.1
```

#### Метод В: Сканер мережі

На вашому ПК (підключеному до того ж Starlink WiFi):

**Windows:**
```cmd
arp -a
```

**macOS/Linux:**
```bash
arp -a | grep 192.168.1
```

Або використовуйте додаток для сканування мережі (Find, Angry IP Scanner).

---

### Крок 3.3: Тест UDP з'єднання

З ПК, підключеного до Starlink WiFi:

**Linux/macOS:**
```bash
# Відправити тестове повідомлення
echo "test" | nc -u 192.168.1.200 24448
```

**Windows (PowerShell):**
```powershell
# Тест з'єднання
Test-NetConnection -ComputerName 192.168.1.200 -Port 24448 -InformationLevel Detailed
```

Якщо з'єднання працює, WIFI232-B2 готовий!

## 6. Вирішення проблем

### Проблема: Немає відповіді на AT команди

| Перевірка   | Рішення                                  |
|-------------|------------------------------------------|
| Підключення | TX→RX, RX→TX (має бути перехресно)       |
| Живлення    | Переконайтеся, що 3.3В або 5В підключено |
| Швидкість   | Спробуйте 115200, 9600, 57600            |
| Час `+++`   | Зачекайте 2 секунди перед відправкою AT  |
| COM порт    | Перевірте правильність вибраного порту   |

### Проблема: `+ok`, але WiFi не підключається

| Перевірка       | Рішення                                     |
|-----------------|---------------------------------------------|
| SSID            | Має точно співпадати (чутливий до регістру) |
| Пароль          | Перевірте на помилки, спеціальні символи    |
| Діапазон WiFi   | WIFI232-B2 підтримує тільки 2.4ГГц          |
| Відстань        | Перемістіться ближче до роутера Starlink    |
| Статус Starlink | Перевірте чи Starlink онлайн                |

### Проблема: Підключено, але немає UDP зв'язку

| Перевірка   | Рішення                                    |
|-------------|--------------------------------------------|
| IP адреса   | Перевірте правильність IP в GroundLink     |
| Порт        | Має бути 24448 (або ваш налаштований порт) |
| Брандмауер  | Тимчасово вимкніть для тесту               |
| Та ж мережа | Обидва пристрої мають бути в одній мережі  |
| VPN         | Якщо віддалено, перевірте підключення VPN  |

### Проблема: Переривчасте з'єднання

| Перевірка   | Рішення                                  |
|-------------|------------------------------------------|
| Сигнал WiFi | Покращіть позицію антени                 |
| Живлення    | Забезпечте стабільне живлення WIFI232-B2 |
| Перешкоди   | Перемістіть від іншої електроніки        |
| Статична IP | Використовуйте статичну IP замість DHCP  |

### Скидання до заводських налаштувань

Якщо щось пішло не так, скиньте WIFI232-B2:

```
+++
AT+RELD
```

Це відновлює заводські налаштування. Вам потрібно буде переналаштувати.

│              КОРОТКА ДОВІДКА WIFI232-B2                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ПОСЛІДОВНЕ З'ЄДНАННЯ                                          │

│  ПІДКЛЮЧЕННЯ (USB-UART → WIFI232)                              │

│                                                                 │

│  AT+RELD                 Заводське скидання                     │

│  ЗНАЧЕННЯ ЗА ЗАМОВЧУВАННЯМ                                     │

│  Локальний порт GroundLink: 24449                               │
│                                                                 │
