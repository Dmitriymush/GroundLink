# Калібрування осі Pitch механізму антени

## Що це і навіщо

Механізм керується платою з ArduPilot AntennaTracker. Правильна калібровка для цього заліза — PWM **350 (крайнє нижнє) / 1350 (центр) / 2350 (крайнє верхнє)** для обох осей.

На деяких екземплярах вісь yaw (азимут) відкалібрована правильно, а вісь pitch (нахил) залишена на заводських значеннях ArduPilot (1000/1500/2000). Симптоми:

- центр pitch зміщений (механізм "дивиться" не туди, куди виставлено);
- механізм не дістає крайніх положень по нахилу;
- у GroundLink показники elevation не відповідають реальному положенню.

Скрипт `scripts/antenna-pitch-calibration.js` перевіряє і виправляє це. Він записує 6 параметрів (SERVO2_MIN/TRIM/MAX і RC2_MIN/TRIM/MAX) через стандартний MAVLink — те саме, що зробив би Mission Planner. Значення зберігаються в пам'яті механізму (EEPROM) і переживають перезавантаження. Прошивка не змінюється.

## Що потрібно

1. **Node.js** на ПК (https://nodejs.org, будь-яка LTS-версія).
2. Файл скрипта `antenna-pitch-calibration.js`.
3. Мережевий доступ до механізму (та сама мережа/VPN, через які працює GroundLink у режимі MAVLINK).
4. IP-адреса та порт механізму — ті самі, що вписані в GroundLink у налаштуваннях антени (наприклад `192.168.31.30`, порт `24448`).

## ВАЖЛИВО перед запуском

- **Закрийте GroundLink** (або щонайменше відключіть антену тумблером Rotator). Запущена програма займає канал зв'язку, і скрипт працюватиме ненадійно.
- Механізм має бути увімкнений і в мережі.
- Під час запису механізм може трохи рухнутись по pitch (перецентрування) — це нормально.

## Команди

Всі команди виконуються в терміналі (cmd/PowerShell/Terminal) з теки, де лежить скрипт.

### 1. Перевірка (нічого не змінює)

```
node antenna-pitch-calibration.js check --host 192.168.31.30
```

Виведе поточну калібровку обох осей і вердикт:

- `pitch відкалібровано правильно (350/1350/2350) ✓` — все добре, нічого робити не треба;
- `pitch НЕ відповідає 350/1350/2350 — запустіть команду fix` — потрібен фікс.

### 2. Фікс

```
node antenna-pitch-calibration.js fix --host 192.168.31.30
```

Скрипт запише кожен параметр і підтвердить його зворотним читанням:

```
Запис параметрів (fix):
  SERVO2_MIN   1000 -> 350 ✓
  SERVO2_MAX   2000 -> 2350 ✓
  SERVO2_TRIM  1500 -> 1350 ✓
  RC2_MIN      1000 -> 350 ✓
  RC2_MAX      2000 -> 2350 ✓
  RC2_TRIM     1500 -> 1350 ✓

Фінальна перевірка:
  ... всі шість зі значком ✓

ГОТОВО: всі параметри записані та підтверджені ✓
```

Скрипт безпечно запускати повторно — вже правильні значення він пропускає.

### 3. Після фіксу

Запустіть GroundLink і **перепідключіть антену** (тумблер Rotator OFF → ON). Програма перечитає калібровку з механізму автоматично.

### 4. Відкат (якщо колись знадобиться)

Повертає заводські значення ArduPilot (1000/1500/2000):

```
node antenna-pitch-calibration.js rollback --host 192.168.31.30
```

## Додаткові параметри

| Опція | За замовчуванням | Опис |
|---|---|---|
| `--host` | 192.168.31.30 | IP механізму |
| `--port` | 24448 | UDP-порт |
| `--sys` | 2 | MAVLink system id трекера |
| `--min` | 350 | Крайнє нижнє PWM (тільки для `fix`) |
| `--trim` | 1350 | Центр PWM (тільки для `fix`) |
| `--max` | 2350 | Крайнє верхнє PWM (тільки для `fix`) |

### Якщо у механізму інші значення PWM

Стандартні 350/1350/2350 підходять для цієї серії механізмів (такі самі, як на осі yaw). Якщо конкретний екземпляр має іншу механіку, значення можна задати явно:

```
node antenna-pitch-calibration.js fix --host 192.168.31.30 --min 350 --trim 1350 --max 2350
```

Де взяти правильні значення: вони визначаються механікою конкретного виробу (виробником/збирачем механізму). Орієнтир — команда `check` показує калібровку осі yaw (SERVO1/RC1): якщо обидві осі механічно однакові, pitch має збігатися з yaw.

## Якщо щось пішло не так

| Проблема | Що робити |
|---|---|
| `немає відповіді від механізму` | Перевірте живлення механізму, IP (`ping <ip>`), чи активний VPN/мережа, чи закритий GroundLink |
| `ПОМИЛКА ЗАПИСУ` або `НЕ ВСІ параметри підтверджені` | Переконайтесь, що GroundLink закритий, і запустіть `fix` ще раз — скрипт продовжить з місця зупинки |
| Механізм поводиться дивно після фіксу | Виконайте `check` і надішліть розробнику повний вивід |
