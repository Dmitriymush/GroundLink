# MAVLink Auto-Tracking — Автоматичне наведення антени

## Огляд

Система автоматичного наведення антени за допомогою MAVLink телеметрії.
Антена автоматично слідкує за дроном, розраховуючи азимут та кут місця
на основі GPS координат дрона та наземної станції.

## Як це працює

```
Польотний контролер (ArduPilot/PX4)
    ↓ Serial (UART)
RPanion-server (на дроні, 10.0.2.100:3000)
    ↓ UDP через VPN
GroundLink (порт 14550)
    ↓ Парсинг MAVLink
Розрахунок азимуту/кута місця (Haversine)
    ↓
Керування антеною (ротатор)
```

**MAVLink повідомлення що використовуються:**
- `HEARTBEAT` (ID 0) — статус з'єднання з дроном
- `GLOBAL_POSITION_INT` (ID 33) — GPS координати дрона (lat, lon, alt)

## Налаштування

### Крок 1: Налаштування RPanion

RPanion має пересилати MAVLink телеметрію на IP оператора.

1. Відкрийте веб-інтерфейс RPanion: `http://10.0.2.100:3000`
2. Перейдіть до **Telemetry** (Телеметрія)
3. Додайте UDP вихід:
   - **Protocol:** UDP
   - **Host:** IP оператора у VPN (наприклад `10.0.2.1`)
   - **Port:** `14550`
4. Збережіть налаштування

> RPanion вже підключений до польотного контролера через Serial.
> Вам потрібно лише додати UDP output для пересилки.

### Крок 2: Налаштування GroundLink

1. Відкрийте сторінку **Antenna Control** (Керування антеною)
2. Увімкніть **Rotator** (перемикач)
3. Оберіть режим **MAVLink** (кнопка-перемикач UDP / MAVLink)

#### Параметри з'єднання:
- **UDP Port:** `14550` (за замовчуванням, можна змінити)
- Натисніть **Listen** (Слухати) — додаток почне прослуховувати порт

#### Координати наземної станції (GCS):
Введіть координати місця розташування антени:
- **Lat:** широта (наприклад `50.4501`)
- **Lon:** довгота (наприклад `30.5234`)
- **Alt(m):** висота над рівнем моря у метрах

> Координати зберігаються автоматично і будуть доступні при наступному запуску.

### Крок 3: Підключення

Після натискання **Listen**:

1. **Жовтий індикатор** "Waiting for GPS data..." — порт відкритий, очікується телеметрія
2. **Зелений індикатор** "Drone GPS acquired" — GPS дані отримані

Коли GPS дані надходять, відображаються:
- Координати дрона (Lat, Lon, Alt)
- Розрахований азимут (Bearing)
- Розрахований кут місця (Elev)
- Відстань до дрона (Dist)

### Крок 4: Автоматичне наведення

Увімкніть перемикач **Auto-track**:
- Компас автоматично повертається до дрона
- Зелена іконка GPS пульсує коли трекінг активний
- Антена рухається за дроном у реальному часі

> Auto-track доступний лише коли введені координати GCS та отримані GPS дані дрона.

## Тестування з симулятором

Для тестування без реального дрона використовуйте симулятор:

```bash
# Базовий запуск (дрон летить колом навколо Києва)
node scripts/mavlink-simulator.js

# З налаштуваннями
node scripts/mavlink-simulator.js --lat 50.4501 --lon 30.5234 --alt 150 --radius 1000

# Швидший рух
node scripts/mavlink-simulator.js --speed 3

# Інший порт
node scripts/mavlink-simulator.js --port 14551
```

**Параметри симулятора:**

| Параметр | За замовчуванням | Опис |
|----------|-----------------|------|
| `--host` | `127.0.0.1` | Адреса куди надсилати пакети |
| `--port` | `14550` | UDP порт |
| `--lat` | `50.4501` | Широта центру кола (Київ) |
| `--lon` | `30.5234` | Довгота центру кола |
| `--alt` | `100` | Висота дрона (метри) |
| `--radius` | `500` | Радіус кола (метри) |
| `--speed` | `1` | Множник швидкості |
| `--rate` | `5` | Повідомлень за секунду |

**Порядок тестування:**

1. Запустіть симулятор: `node scripts/mavlink-simulator.js`
2. У GroundLink: Rotator → MAVLink → Listen
3. Введіть координати GCS: `50.4501`, `30.5234`, `0`
4. Увімкніть Auto-track
5. Спостерігайте як компас слідкує за "дроном"

## Режими роботи

### UDP (поточний)
Пряме керування ротатором через WIFI232-B2 модуль.
Оператор вручну задає азимут та кут місця.

### MAVLink (новий)
Автоматичне наведення на основі GPS телеметрії дрона.
Антена автоматично слідкує за дроном.

Режими перемикаються кнопкою **UDP / MAVLink** у панелі ротатора.
Обидва режими можуть працювати з тим самим ротатором — змінюється лише
джерело команд (ручне або автоматичне).

### Формули розрахунку

**Азимут (bearing):**
```
bearing = atan2(sin(dLon)·cos(lat2), cos(lat1)·sin(lat2) - sin(lat1)·cos(lat2)·cos(dLon))
```

**Відстань (Haversine):**
```
a = sin²(dLat/2) + cos(lat1)·cos(lat2)·sin²(dLon/2)
distance = R · 2 · atan2(√a, √(1-a))
```

**Кут місця (elevation):**
```
elevation = atan2(altDrone - altGCS, distance)
```

### Порт за замовчуванням

`14550` — стандартний порт MAVLink для GCS (Ground Control Station).
Цей порт використовується за замовчуванням у Mission Planner, QGroundControl та інших GCS.
